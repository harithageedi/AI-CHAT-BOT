#  AI ChatBot

A Java-based console application developed as part of the **CodeAlpha Java Programming Internship** that simulates basic conversational interactions using predefined responses and simple intent recognition. The project demonstrates core Java programming concepts, object-oriented design, collections, file handling, and user interaction through a modular architecture.

## Overview

AI ChatBot is a console application developed in Java that allows users to interact with a chatbot capable of responding to greetings, answering common programming questions, performing basic arithmetic operations, detecting simple emotions, displaying the current date and time, and maintaining chat history.

## Internship

This project was developed as part of the **CodeAlpha Java Programming Internship** to strengthen practical Java development skills through real-world programming tasks.
---

## Features

- Desktop Chat Application using Java Swing
- User name recognition within the current session
- Greeting and conversation handling
- Basic emotion detection (happy, sad, angry, tired)
- Current date and time display
- Arithmetic calculator
- Random programming jokes
- Random motivational quotes
- Help menu listing available commands
- Chat history saved to a text file
- Modular class-based architecture

##  Getting Started

### Prerequisites

- Java JDK 17 or later
- VS Code (or any Java IDE)

### Compile the project

```bash
javac *.java
```

### Run the application

```bash
java Main
```

##  Supported Commands

| Command | Description |
|---------|-------------|
| hello / hi | Greeting |
| my name is \<name> | Stores the user's name |
| who am i | Displays the stored name |
| how are you | Basic conversation |
| date | Shows current date |
| time | Shows current time |
| calculate 25+10 | Performs arithmetic calculations |
| joke | Displays a random programming joke |
| motivate me | Displays a motivational quote |
| java | Information about Java |
| python | Information about Python |
| c++ | Information about C++ |
| placement | Placement advice |
| project | Project guidance |
| help | Displays available commands |
| bye | Ends the conversation |
| exit | Closes the application |
